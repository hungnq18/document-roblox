# Beat the Horde — Complete Markdown Documents

Bộ tài liệu được xuất từ Google Drive ngày 27/10/2026:

- `DOC-01_GDD.md` — toàn bộ Game Design Document
- `DOC-02_GSD.md` — toàn bộ Game System Design, bổ sung Mermaid BL-V2
- `DOC-03_Balance_Calculator.md` — tất cả tab và ô có dữ liệu trong workbook, kèm công thức và cached values

**Hình gốc:** Thư mục `assets/` chứa hình PNG trích từ nguồn Markdown xuất bởi Google Drive; đường dẫn trong Markdown là tương đối. Xem cả thư mục cùng nhau hoặc giải nén ZIP để ảnh hiển thị chính xác.

**Lưu ý về DOC-03:** Markdown không chạy lại Excel formulas và không giữ định dạng/biểu đồ native Google Sheets; toàn bộ giá trị/công thức đọc được được giữ dưới dạng văn bản.

**Lưu ý về bản vẽ:** Các hình PNG là bản render gốc, Mermaid là bản chỉnh sửa được nhưng là sơ đồ hệ thống bổ sung, không phải phục dựng pixel-perfect của từng hình gốc.
